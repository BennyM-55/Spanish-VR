# Features

## Implemented features

### 3D restaurant environment

The simulation uses a virtual café/restaurant setting. The supplied files include the `Cafe.unity` scene and Mexican Restaurant environment assets.

### Player navigation and camera

Players move around the scene with an accompanying camera. The café scene references a player movement component and Cinemachine objects.

### Character conversations

Selecting a character initiates an interactive conversation. This behavior is confirmed working by the developer; the scene also references `CafeConversationStarter`.

### Guided Spanish dialogue

The current conversation experience presents Spanish dialogue and selectable responses. Players use those responses to progress through interactions. The developer confirms this feature is working.

### Environmental audio

Café music and background chatter support the setting. Corresponding audio objects are visible in the scene; the developer confirms implemented features are working.
