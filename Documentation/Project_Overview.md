# Project Overview

## Purpose

SpanishCafe provides a virtual café/restaurant setting for practicing conversational Spanish. Users explore a 3D environment, initiate conversations with characters, and select responses to work through everyday language scenarios.

## Audience

Spanish learners who want structured, scenario-based practice in a simulated environment.

## Objectives

* Encourage everyday Spanish vocabulary and sentence comprehension.
* Support interactive practice through character conversations.
* Present language learning in a recognizable restaurant setting.
* Create a foundation for future spoken-language practice.

## Current scope

The developer confirms that navigation, character interaction, guided dialogue, response selection, and the café experience are implemented and working. The supplied `Cafe.unity` scene references movement, conversation, camera, and audio components.
