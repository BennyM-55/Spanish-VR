# Installation Guide

## Requirements

* Unity Hub
* The Unity Editor version configured for the **complete project**
* The complete project directory

## Open the project

1. Obtain or clone the complete SpanishCafe Unity repository.
2. Open **Unity Hub** and choose **Add project from disk**.
3. Select the folder containing `Assets`, `Packages`, and `ProjectSettings`.
4. Open it using the Editor version specified by that project.
5. Wait for asset import and package resolution.
6. Open the `Cafe` scene, supplied in the reviewed files as `Scenes/Cafe.unity`.
7. Press **Play**.
8. Navigate the café and select a character to begin a Spanish conversation.

## Notes

* Unity may require package imports or downloads based on the complete project's configuration.
* The exact project-relative location of `Cafe.unity` may vary depending on how the complete repository organizes `Assets`.

## Troubleshooting

If a scene or component is missing, confirm you opened the **complete project**, not only the two review archives. Check Unity's Console for missing dependencies or asset references.
