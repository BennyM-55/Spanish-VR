# SpanishCafe

SpanishCafe is an interactive 3D Spanish-practice simulation built with Unity. Players explore a virtual café/restaurant, select characters, and practice Spanish through guided dialogue and response choices.

## Project status

The current gameplay features are **implemented and working**, as confirmed by the project developer. The supplied Unity scene and restaurant assets were reviewed for documentation; this review is not a separate runtime test. Microphone input, AI-generated conversations, and pronunciation feedback are **future features**.

## Current features

* 3D café/restaurant environment
* Player movement and camera controls
* Character selection to start conversations
* Guided dialogue with selectable responses
* Background café audio

## Getting started

1. Open the **complete Unity project** using Unity Hub and its configured Unity Editor version.
2. Let Unity import project assets and packages.
3. Open the café scene (`Cafe`, supplied as `Scenes/Cafe.unity`).
4. Press **Play** to explore and interact with characters.

The two reviewed archives contain scene files and restaurant assets, **not** a complete standalone Unity project. See the [Installation Guide](Documentation/Installation_Guide.md) for details.
